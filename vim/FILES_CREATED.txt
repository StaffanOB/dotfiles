================================================================================
TESTING PROCEDURE
================================================================================

1. Install dependencies:
   pip install ruff black isort

2. Open Vim and install plugins:
   vim
   :PlugInstall

3. Test Python LSP:
   vim test.py
   - Type code, test 'gd', 'K', <C-Space>

4. Check startup time:
   vim --startuptime /tmp/test.log -c quit
   tail -1 /tmp/test.log

5. Check optimization status:
   vim
   :OptimizationStatus

================================================================================
ROLLBACK PROCEDURES
================================================================================

Full Rollback:
  cp vimrc.backup-20260128 vimrc
  vim
  :source ~/.vimrc
  :PlugInstall

Partial Rollback (disable phases):
  Edit vimrc, set phase variables to 0:
    let g:enable_phase_1 = 0  # Back to CoC
    let g:enable_phase_2 = 0  # Back to vim-airline
    let g:enable_phase_3 = 0  # Back to old ALE
    let g:enable_phase_4 = 0  # Disable Databricks
    let g:enable_phase_5 = 0  # Disable lazy-loading
